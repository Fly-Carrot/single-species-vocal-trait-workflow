# Teaching Data

## Included Demo

`demo/common-tailorbird-denoised.wav` is a 9.6-second, mono, 44.1-kHz project-provided teaching sample. It is also available in the companion data repository.

Use it to:

- build an audio manifest;
- create short clips;
- inspect a waveform and spectrogram;
- practise defining complete vocal units.

The demo is illustrative. The statistical models use the validated analysis tables downloaded by `analysis/download_public_data.py`.

## Templates

`templates/manual-validation-template.csv` provides the minimum fields for a review log.
