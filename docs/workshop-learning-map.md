# Workshop Learning Map

The repository lessons follow the teaching sequence in the Kingfisher Forum workshop deck.

| Workshop section | Repository lesson | Classroom focus |
| --- | --- | --- |
| ecological acoustics and PAM | [Orientation](00-orientation.md) | connect sound to ecological questions |
| field equipment and deployment | [Field recording](01-field-recording.md) | plan comparable recordings |
| preprocessing and denoising | [Audio preparation](02-audio-preparation.md) and [Audition walkthrough](09-audition-audio-preparation.md) | distinguish model clips from measurement-ready vocal clips |
| acoustic-scene classification | [Sound-event detection](03-sound-event-detection.md) | convert sound into event labels |
| species-level recognition | [Species screening](04-species-screening.md) | find focal-species candidates |
| interactive sound software | [Manual verification](05-manual-verification.md) | inspect model candidates |
| Avisoft workflow | [Vocal traits](06-vocal-traits.md) and [Avisoft walkthrough](10-avisoft-vocal-trait-measurement.md) | mark syllables and check exported traits |
| Common Tailorbird case study | [Aggregation](07-aggregation.md) | follow counts across data scales |
| BLMM and GAM case-study results | [Models and sensitivity](08-models-and-sensitivity.md) | connect models to ecological questions |
